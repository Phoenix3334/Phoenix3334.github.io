01 · MAIN PROJECT

MiniCPM-o 4.5 on NVIDIA B300 and Ascend 910C ↗

Built the training-to-runtime path for real-time full-modal inference: B300 draft-model training, DSpark draft execution with real multimodal samples, draft-aware safetensors-to-GGUF conversion, and deployment on Ascend 910C. 02 · DPC

Generation health and user routing isolation ↗

Identified that generation health requests advanced the same Data Parallel Controller routing state used by user traffic. PR #35721 gives health traffic independent routing state and preserves balanced user dispatch.

MLA KV index localization during decode retraction ↗

Localized DCP-widened logical KV indices before CPU backup and restore touches the rank-local MLA buffer. The fix keeps KDA and Mamba recurrent-state indexing separate and restores into newly allocated logical locations after re-admission.

Current research direction

Adaptive inference systems

Roofline analysis estimates the software–hardware ceiling. Runtime signals then locate whether the active limit comes from compute, memory, communication, scheduling, or capacity.

How can the inference layer adapt to changing workloads and hardware while preserving efficiency and correctness?

01

Observe

Prefill/decode phase, batch shape, OI, GPU utilization, HBM traffic, and per-rank work supply

02

Classify

Compute, memory, communication, scheduler fragmentation, rank imbalance, or KV-capacity limit

03

Adapt

Chunk size, prefill admission timing, batching, DP/TP/EP layout, kernels, cache, and graph policy

04

Verify

Controlled A/B runs using TPS, TTFT, dispatch balance, traces, correctness gates, and long-run stability
