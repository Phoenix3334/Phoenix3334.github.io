Long-term research lens

Systems for model-centric workloads

What interests me is not one serving framework, but how systems abstractions, resource management, and execution mechanisms should evolve when models become a dominant computational workload.

The workload changes. The systems questions remain.

Concrete MPhil problem — Adaptive Inference Systems for Real-World Workloads. Real serving workloads are non-stationary: request arrivals, sequence lengths, Prefill/Decode ratio, modality, SLO, cache pressure, and hardware availability can change over time. The next step beyond offline characterization is to close the loop and make runtime decisions online.

01

Observe

Workload phase, arrival pattern, sequence distribution, cache pressure, SLO, telemetry, and resource availability.

02

Model

Estimate how workload × hardware × policy maps to throughput, latency, memory use, and switching cost.

03

Adapt

Change one or two high-impact decisions first: batching, cache policy, parallel layout, or execution strategy.

04

Validate

Require runtime invariants, safe fallback, controlled regression, and long-run stability — not performance alone.

Deliberately bounded scope: start with one representative workload family and a limited heterogeneous hardware set. Adaptive inference is a concrete systems problem through which I want to study the broader question of model-centric resource management.

The framework may change. The systems question remains.
