02 · DPC

Generation health and user routing isolation ↗

Identified that generation health requests advanced the same Data Parallel Controller routing state used by user traffic. PR #35721 gives health traffic independent routing state and preserves balanced user dispatch.

03 · DCP

MLA KV index localization during decode retraction ↗

Localized DCP-widened logical KV indices before CPU backup and restore touches the rank-local MLA buffer. The fix keeps KDA and Mamba recurrent-state indexing separate and restores into newly allocated logical locations after re-admission.
