# Feihong Guo — AI Systems

Static source for the personal GitHub Pages site.

## Publish

1. Create or rename a public repository to `Phoenix3334.github.io`.
2. Put `index.html`, `og.jpg`, and `.nojekyll` at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.

The site will be available at <https://phoenix3334.github.io>.
